# Research gathered for this class

When your AI looks up research for your challenge, it saves it here, so it can use it all year and so you can read exactly what it found. Each idea says where it came from and how strong the evidence is. Your notes on what worked in your room ("the if-then plans landed in 1st period") go here too, without student names. Updates never touch this folder.

*For the AI:* follow `brain/evidence-engine.md`. Name new packs after the goal (`[goal].md`) and teacher notes `[goal]-notes.md`. Class-level only, never a student's name. Read this folder before `brain/evidence-packs/`.
