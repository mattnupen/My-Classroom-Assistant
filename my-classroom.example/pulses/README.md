# Weekly class summaries

Each week, **Class Pulse** turns your gradebook into a short class summary with no names — just totals. Your AI reads the newest one here.

1. In Class Pulse, click **Download**. The file (named like `pulse-2026-09-21.md`) lands in your Downloads folder.
2. Drag it into this folder.
3. In the chat, say **"run Monday."**

Can't find the file? Click **Copy** in Class Pulse instead and paste it into the chat.

Keep them all — together they're your class's trend line. Practice files from the demo class (`pulse-DEMO-…`) don't belong here. Only these summaries go here; Class Pulse's comparison file (`class-pulse-snapshot-….json`) stays wherever you keep it.
