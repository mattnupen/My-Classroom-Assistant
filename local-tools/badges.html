Badges & Certificates

Print certificates that celebrate effort and comebacks. Use it on celebration days or at the end of a unit.

Step 1 — Your class memory file

A small file that remembers your badges and who got them (Random Groups uses the same one). First time? Click Start a new memory file. It holds student names, so keep it on this computer — Documents is fine — not in your classroom assistant folder.

Step 2 — Class roster (from your gradebook file)

No file yet? Load demo class tries it with 24 made-up students. To get your own: in your gradebook, find Export (or Download) and choose CSV.

Step 3 — Define your badges

Each badge has a name, description, icon (emoji), and color. Add or remove as you go. They're saved in your memory file when you download it (Step 5).
