First time? Add the app builder to Claude

It’s an add-on that teaches Claude to build classroom apps safely. You do this once — about five minutes.

  1. In Claude, click your name at the bottom left, then open Settings → Capabilities and switch on Code execution and file creation. It only lets Claude make files for you; it doesn't change anything else on your computer.
  2. Click Customize → Skills, then + → Create skill → Upload a skill. Choose teacher-app-builder-skill-upload.zip from your My Classroom Assistant folder. Don’t unzip it first.
  3. Check it worked: in a new Cowork chat, type build me an app. Claude should ask what you’d like the app to help you do.

Step-by-step guide, and what to do if something doesn’t match — or just ask Claude: “help me add the app builder.”

On a school or district account? Your administrator may need to turn skills on first.

Then: copy an idea below, paste it into a Cowork chat, and answer a question or two. Your new app shows up in this sidebar under Your apps. Every app that uses your class list has a Try it with a made-up class button — try that first.
Why this is safe: every app built this way is one file that runs on your computer. It never sends anything anywhere and never saves your students’ information — the same rules every app in Class Tools follows. Claude checks each one before adding it here.
