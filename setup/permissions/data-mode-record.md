## What this option means for student information

**Offline (the default).**
Student names, grades, and rosters are never sent to Claude. They are handled only by offline, single-file browser apps on the teacher's own computer, which process the data without sending it anywhere and keep nothing after the tab closes. Claude receives only class totals with no names (e.g., "8 students behind on Unit 3"). This is built into how the project works, and every app it builds passes an automated check for it.

**Claude for Teachers (requires the district permission recorded below).**
The teacher uses Claude through [Claude for Teachers](https://claude.com/solutions/teachers) and may share student information with it directly — in the chat, or by dropping a file in the inbox folder inside the classroom folder — under Anthropic's [Claude for Teachers data terms](https://support.claude.com/en/articles/15926041-claude-for-teachers-your-data-and-our-terms), which include a K-12 Data Processing Addendum written for FERPA. These still hold: Claude uses only what each task needs and is not asked for sensitive records (IEP/504, health, counseling, discipline, custody, immigration status); no student's name is saved into the classroom's lasting notes or dashboards or shown to the class; drafts with a student's name (a note home, say) are given in the chat and not kept between chats; if the teacher asks for one as a file, the teacher deletes it once it's been used, and empties the inbox folder after each use.

- No student accounts, logins, or student–AI conversations. The teacher is the go-between for everything.

- The teacher reviews everything before a student or family sees it.
